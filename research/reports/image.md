# 图片模态调研（初筛稿）

## 覆盖方向

GAN 生成图检测、扩散模型生成图检测、换脸检测、人脸重演检测、抗扰动泛化检测。

## 当前技术框架

- **频域/残差取证**：捕捉生成器上采样、纹理统计和相机成像不一致；对后处理、重采样和新生成器敏感。
- **判别式深伪检测**：以 CNN/Transformer 学习真实与伪造表征；部署成熟，但跨数据集和跨生成器性能必须单独验证。
- **扩散反演/噪声轨迹**：利用扩散图像在逆扩散或噪声残差上的差异；对扩散生成器更有针对性，计算量和模型依赖更高。
- **人脸区域与时空线索**：检测身份替换、重演和局部编辑；需要明确人脸裁剪、区域标注和压缩条件。
- **统一基准/集成评测**：将多种模型、数据集和扰动纳入同一协议；不等同于单个检测器。

## 首批官方项目入口

详见 [图片仓库快照](../source-snapshots/image-repositories-2026-08-12.md)。目前仅完成页面级初筛，尚未形成性能排名，也未满足每个细分方向不少于 6 个合格方案的要求。

## 扩散生成图检测：已发现的官方代码候选

| 方案 | 核心逻辑 | 适用边界/待核验项 |
|---|---|---|
| DIRE | 用预训练扩散模型重建输入，利用 Diffusion Reconstruction Error 区分真实与扩散生成图 | 计算成本、归档维护状态、不同扩散家族和压缩条件 |
| UniversalFakeDetect | 训练于一种生成模型并迁移检测其他生成模型，强调跨生成器泛化 | GAN→扩散迁移、训练/测试生成器隔离、权重和实验表 |
| DRCT | 扩散重建后进行 margin-based contrastive training，将真实/生成/重建样本联合训练 | DRCT-2M 许可、重建配置和跨模型指标 |
| LaRE2 | 在 latent space 使用重建误差，降低特征提取成本 | DIFT/LASTED 依赖、GenImage 划分和部署资源 |
| NASA-Swin | 噪声信息与 Swin/异常注意力结合，面向扩散生成检测 | TIFS 论文版本、权重、扰动和跨域性能 |
| DEUA | 通过扩散 epistemic uncertainty 与 asymmetric learning 建模不确定性 | 许可证虽为 Apache-2.0，仍需核验权重和完整复现 |
| LATTE | 对潜变量轨迹进行 embedding，捕获扩散生成过程中的轨迹线索 | README 论文版本链接不一致风险、指标实验表 |

这 7 项满足“候选数量”而非“合格方案”门槛；只有完成许可证、代码/权重类型、论文实验条件和复现状态后，才能计入方向完成数。

README 实验条件和数据证据已单独记录在[图片检测证据快照](../source-snapshots/image-evidence-2026-08-12.md)。当前唯一可直接转录的数值是 DRCT README correction note 中绑定 **BigGAN + Conv-B** 的 59.81% Accuracy；其余“泛化/鲁棒/优于”表述暂不转成排名数字。

数据集和基准框架的独立台账见 [datasets/image.md](../datasets/image.md)。FaceForensics 与 DeepfakeBench 已确认官方页面入口，但尚未把网页标题当作规模、许可或性能证据。

## 必须补齐的实验条件

后续所有 AUC/F1/准确率必须绑定生成器（如 GAN、扩散模型、换脸工具）、真实数据来源、训练/测试划分、压缩与分辨率、跨数据集设置和阈值协议。FaceForensics 与 DeepfakeBench 需要进一步拆分数据集角色、任务定义和许可边界。

## 当前缺口

- GAN、扩散、换脸、重演、抗扰动五个方向均未达到“至少 6 个官方开源方案”的完成门槛。
- 当前只有 DIRE 完成了页面标题级的扩散检测身份核验；其余候选仍需补论文、LICENSE、权重/代码类型和实验表。
- 尚未记录任何未经条件绑定的 AUC/F1 数字，避免把不同数据划分或压缩条件下的结果错误横排。

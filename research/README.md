# 合成内容检测技术调研

本目录承载“生成合成内容检测技术能力基准测试”的可审计调研资料。所有进入主清单的模型、数据集和性能结果必须能够追溯到论文、官方项目页、官方代码仓库或官方数据发布页。

## 调研边界

- 文本：生成文本检测、风格仿冒归因、生成来源溯源、跨语言泛化。
- 图片：GAN、扩散生成、换脸、人脸重演、抗扰动泛化。
- 音频：TTS、语音转换、语音克隆、扰动泛化、实时检测。
- 视频：换脸、人脸重演、说话人脸、唇音同步、时序一致性。
- 合成 3D：数字人、虚拟场景、3D 模型真伪。

## 证据等级

1. **A：官方一手证据** — 原论文/作者或机构主页、官方 GitHub/GitLab、官方数据集页。
2. **B：公开基准证据** — 可定位到具体数据集、划分、扰动和指标的实验表格。
3. **C：辅助证据** — 第三方复现、项目汇总或社区实现；不得单独支撑主清单结论。

没有官方原始实现的方案只能列入“补充参考”，不能进入官方开源主清单。性能数字必须绑定任务、数据集、划分和退化条件。

第一批视频换脸服务器评测包装器在仓库根目录 [`src/video_eval/`](../src/video_eval/)，协议见 [`docs/video-eval-protocol.md`](../docs/video-eval-protocol.md)。


## 文件约定

- `evidence-ledger.md`：逐条来源、核验状态和缺口记录。
- `benchmark-mapping.md`：将方案能力映射到基准测试指标与场景；含 Q3 赛道可测/对照/不可测。
- `reports/`：按模态分篇。**音频/视频报告开头是测试决策卡与赛道入准表。**
- `datasets/`：数据集规格、官方下载入口和许可核验（[`audio.md`](datasets/audio.md)、[`video.md`](datasets/video.md)、[`image.md`](datasets/image.md)）。
- `coverage-matrix.md`：22 个细分方向。6/3 只是理想规模；稀缺方向用联合模型作测试候选。

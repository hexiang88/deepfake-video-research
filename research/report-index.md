# 全模态调研报告索引

这些报告面向需要进行技术选型和基准测试设计的读者，强调路线差异、实验条件、能力边界和证据状态；不把阶段性候选写成最终排行榜。

## 报告

测试人员从音频/视频报告的 **§1 总决策卡** 和 **§2 赛道入准表** 开始。`可测` / `可对照` / `须备注` 以入准表为准。6/3 不是开测门槛。覆盖见 [全模态覆盖矩阵](coverage-matrix.md)。

- [文本模态](reports/text.md)：生成文本检测及来源归因/跨语言候选。
- [图片模态](reports/image.md)：GAN/扩散图像、换脸/重演和鲁棒性路线。
- [音频模态](reports/audio.md)：闭集、跨域、VC/克隆/实时均可测；后三者用通用反欺骗或离线模型代理并加备注。
- [视频模态](reports/video.md)：换脸、Talking Face、定位可测；人脸重演、唇音用联合/相邻模型开测并加备注。
- [合成 3D 模态](reports/3d.md)：数字人、虚拟场景和 3D 资产真伪路线。

## 阅读说明

“官方代码候选”表示已找到作者/机构仓库并完成基础元数据核验；“合格方案”还必须完成代码/权重开放类型、许可证、实验条件和性能证据核验。音频/视频已开始数据集入口核验，见 `datasets/`；未完成许可与哈希的条目保持“入口已发现”。

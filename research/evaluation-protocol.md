# 统一评测协议草案

本文件用于把论文中的异构结果转换为可比较的基准测试记录。它不是任何模型的性能结论。

## 1. 数据拆分与泄漏控制

- 按原始来源、身份、作者、视频主体、说话人和生成器分组拆分，禁止同源样本跨训练/验证/测试。
- 对生成内容按生成器家族拆分：`known-generator`、`held-out-generator`、`held-out-family`。
- 文本要按作者/体裁/语言分组；图片和视频要按主体与原始素材分组；音频要按说话人和录音环境分组。
- 训练阶段不得使用测试集的压缩版本、同一原始素材的裁剪版本或同一生成轨迹的不同采样。

## 2. 精度指标

每个方向至少报告 ROC-AUC、AP、F1、Precision、Recall，并给出 95% bootstrap 置信区间。阈值型指标必须说明阈值是在验证集、固定开发集还是测试集上确定。

- **二分类**：ROC-AUC + AP + macro-F1；类别不平衡时不得只报 Accuracy。
- **音频/视频反欺骗**：补充 EER、min t-DCF（若任务协议支持），明确分数方向和 trial 定义。
- **来源归因**：macro-F1、balanced accuracy、混淆矩阵，并区分“先检出伪造再归因”和直接多类归因。
- **区域/帧定位**：像素/区域 IoU、区域 AP、帧级 AUC；明确标注粒度。

## 3. 鲁棒性矩阵

每个模型至少在原始质量、压缩、缩放/重采样、裁剪、噪声、模糊和局部编辑条件下测量性能，并记录相对衰减：

`衰减率 = (原始条件指标 - 退化条件指标) / 原始条件指标`。

所有退化条件必须记录参数：图像编码质量、视频编码器/码率、音频采样率/编码、分辨率、噪声强度、攻击预算和随机种子。

## 4. 泛化与开放集

- **跨生成器**：训练生成器不出现在测试生成器集合中。
- **跨域**：单独报告地域、语言、体裁、设备和平台分布变化。
- **少样本/零样本**：记录可用标注量、是否调阈值、是否更新权重。
- **OOD**：报告未知生成器/未知伪造类型的 AUROC、FPR@TPR 和风险-覆盖率曲线；不能用已知类准确率替代 OOD 结果。

## 5. 效率与复现

效率数据必须记录硬件、软件版本、批大小、数值精度、预处理、模型加载是否计时和端到端边界。官方代码、权重、依赖、数据下载和 LICENSE 任一缺失，都要在复现状态中单独标记，不得写成“完全开源”。
